# Workflow templates

Ready-to-import n8n workflows for Vietnamese businesses. **Arrives in milestone M1** (after the Compose kit).

Each template is a folder with `workflow.json`, `README.md` (what it does, credentials needed, how to test), `test-payload.json` and a screenshot. Import via the n8n UI or `make -C compose import-template NAME=<folder>`.

Planned first five: `zalo-form-notify` · `vietqr-payment-link` · `sheets-order-log` · `gchat-approval` · `ai-faq-bot`.

Want one that is not listed? Open a [template request](https://github.com/nhhandevops/n8n-prod-kit/issues/new?template=template-request.yml).
